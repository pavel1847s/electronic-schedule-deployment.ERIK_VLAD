# Электронное расписание

## Назначение
Система предназначена для просмотра расписания студентами и преподавателями.

## Возможности
- просмотр расписания группы;
- просмотр расписания преподавателя;
- публикация замен;
- разграничение прав доступа.

## Ответственные
- менеджер развёртывания — Хайруллин.Э.Р;
- менеджер сопровождения — Карпов.В.Н.
