# Версия 1.0.0

## Добавлено
- просмотр расписания групп;
- просмотр расписания преподавателей;
- авторизация;

## Известные ограничения
- мобильная версия находится в разработке;
- репозиторий содержит учебный макет, а не готовую промышленную систему.

## Обновление
Перед обновлением создать резервную копию, заменить файлы новой версии, проверить настройки и выполнить smoke-тест.
